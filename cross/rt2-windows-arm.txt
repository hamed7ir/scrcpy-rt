# NOT PART OF ANY SUPPORTED BUILD. scrcpy-rt builds by hand (scripts/catalogue-scrcpy.sh and

# own Meson build instead, kept because the rc.exe finding below is worth having written down.
#
# THE ONE FILE IN THIS REPOSITORY THAT IS NOT PARAMETERISED. A Meson cross file is read as
# literal data -- it has no variable expansion and cannot see the environment -- so the paths
# below are the original machine's and would have to be edited by hand. Everything else in
# this repo takes its paths from config.sh. If you revive this path, generate this file rather
# than editing it.
#
# The '@rsp' form in the compiler exelist is not decoration. Meson's `--internal rc` wrapper
# splats the whole compiler exelist after --cl, and argparse's nargs='+' will not absorb a token
# starting with '--', so an inline --target= falls through to rc.exe and dies with RC1106.
# A response file survives being splatted because '@' is not a prefix character.
# Measured in lite-xl Stage 2; do not "simplify" it away.
